**More Than a Machine. A Legacy.**

## About

BMWorld is a BMW enthusiast website created to explore the world of BMW automobiles. It brings together the brand's iconic models, rich heritage, M Performance, and automotive culture through an interactive web experience.

The project aims to showcase BMW's legacy, engineering, and design through a modern and engaging interface.

## Features

- **BMW Models:** Explore different BMW series, models, and specifications.
- **Model Details:** View detailed vehicle information, specifications, and image galleries.
- **BMW History:** Discover important milestones in BMW's journey.
- **M Performance:** Explore BMW's performance-focused lineup.
- **3D Experience:** An interactive space dedicated to BMW's design and engineering.
- **Gallery:** Explore a collection of BMW vehicles and automotive visuals.
- **Cinematic Introduction:** A video-based introduction to the website.
